You need Bun 1.2.22 or newer. Local development does not need a Cloudflare account.

## Create the app

`chardb init` writes into the current directory, so start with an empty one.

```bash
mkdir my-chardb-app
cd my-chardb-app
bunx @chardb/core@0.1.0 init my-chardb-app
bun install
bun run typecheck
bun run test
bun run build
```

The generated test boots a Worker, applies the first schema migration, creates an organization, and reads back one message. If any command fails, fix it before starting the app.

## Run it

Start the Worker and web app together.

```bash
bun run dev
```

Open the local URL printed by Vite. The app signs in anonymously, then creates a Better Auth account for that browser.

Try the complete path once.

1. Create an organization.
2. Open the same organization in a second tab.
3. Post a message and watch both tabs update.
4. Restart `bun run dev` and reload the persisted message.

## Know the four files

You will make most changes here:

- `src/schema.ts` declares tables and ownership.
- `src/queries.ts` declares the reads available to clients.
- `src/api.ts` declares mutations.
- `src/worker.ts` combines Chardb, Better Auth, and your routes.

Next, read [Ownership](/ownership). It explains why `organizationId` controls placement and access rather than acting like an ordinary foreign key.
