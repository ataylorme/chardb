---
title: "Quickstart"
description: "Generate, check, and run the app shipped by @chardb/core 0.1.0."
---

You need Bun 1.2.22 or newer. You do not need a Cloudflare login for local development.

`chardb init` writes into the current directory. Create an empty one first:

```bash
mkdir my-chardb-app
cd my-chardb-app
bunx @chardb/core@0.1.0 init my-chardb-app
bun install
bun run typecheck
bun run test
bun run build
```

The CLI refuses a nonempty directory.

Now start both local servers:

```bash
bun run dev
```

The script starts Wrangler, applies the generated migration, and then starts Vite. Open the URL it prints.

The app signs in anonymously. Try the whole path once:

1. Create an organization.
2. Post a message and watch the live query replace its result.
3. Attach a JPEG or PNG through the local R2 binding.
4. Restart `bun run dev` and reload the persisted message.

`bun run test` covers the same server path in workerd. It migrates a fresh database, creates an organization, and writes and reads one message.

Next, read [The data model](/data-model). It shows the three files you will change first.
