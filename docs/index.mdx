# A real database inside your Worker

Chardb gives a Cloudflare Worker one typed database binding. Organization rows, Better Auth membership, file ownership, and live-query routing share the same organization boundary.

The generated app is a working message board. It signs in through Better Auth, creates organizations, writes and streams organization messages, stores optional image attachments in R2, and survives a local Wrangler restart.

<Note>
  `@chardb/core@0.1.0` is a preview for data you can rebuild. The organization SQL, live-query, migration, local R2, and deployment paths are implemented. Backup, restore, failover, and automatic resharding are not.
</Note>
