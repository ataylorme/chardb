# A real database inside your Worker

Chardb gives a Cloudflare Worker one typed database binding. Better Auth organizations decide where rows live and who can read or write them.

The starter is a working message app with live queries and optional R2 attachments. Generate it, run it, then replace the message table with your own schema.

<Note>
  `@chardb/core@0.1.0` is for data you can rebuild. It has no backup, restore, failover, or automatic resharding path.
</Note>
