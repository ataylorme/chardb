# A real database inside your Worker

CharDB gives a Cloudflare Worker a typed database binding. The Worker owns Better Auth, Durable Object storage, and registered operations. This repository includes React and Rust clients that call those operations through the Worker's public URL.

The generated app includes organization messages, live queries, and an authenticated R2 attachment path. Generate it first. Its schema, tests, Wrangler config, and deployment scripts are the reference application.

Review the operational limits in [Plan ahead](/plan-ahead) before using CharDB with data you cannot recreate.
