# A real database inside your Worker

Chardb gives a Cloudflare Worker a typed database binding. Better Auth users or organizations decide where rows live and who can read or change them.

The generated app includes organization messages, live queries, and an authenticated R2 attachment path. Generate it first. Its schema, tests, Wrangler config, and deployment scripts are the reference application.

<Warning>
  Chardb is experimental. Coordinated SQLite, R2 file, and Vectorize recovery is implemented. Automatic regional failover and a production SLA are not.
</Warning>
