# A real database inside your Worker

Chardb gives a Cloudflare Worker one typed database binding for SQL, files, vectors, and live queries. Better Auth decides who owns each row and who can read or change it.

The starter is a working chat app. Generate it, run it, then replace the message table with your own schema.
